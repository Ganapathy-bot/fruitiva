# Project Vision & Constitution

> Read this file before each FRUITIVA Stitch loop iteration.

## 1. Core Identity
* **Project Name:** FRUITIVA
* **Stitch Project ID:** `18187089592972698893`
* **Mission:** Teach fruit processing through accurate recipes, practical workflows, and value-added product inspiration.
* **Target Audience:** Learners, home processors, food entrepreneurs, and agricultural science students.
* **Voice:** Clear, warm, practical, scientifically careful, and encouraging.

## 2. Visual Language
* **Primary:** Premium food-tech
* **Secondary:** Clean and educational
* **Tertiary:** Warm, botanical, and appetizing
* **Theme:** Dark botanical surfaces with warm orange and white accents.

## 3. Architecture & File Structure
* **Root:** `site/public/`
* **Experience:** Four connected, vertically scrollable mobile views in a single responsive app; bottom navigation links Home, Recipes, Process Lab, and Saved.
* **Stitch source:** Separate mobile screens in the FRUITIVA Stitch project.
